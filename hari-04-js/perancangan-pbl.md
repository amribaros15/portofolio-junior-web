# Perancangan Program Pengolah Nilai

## Tujuan
Membuat aplikasi konsol untuk mengelola data nilai siswa dan menampilkan statistik serta predikat siswa.

## Menu

1. Input nilai siswa
2. Tampilkan statistik
3. Tampilkan predikat per siswa
4. Keluar

## Data
daftarNama[]
daftarNilai[]

## Aturan Penilaian
A : >= 85
B : 70 - 84
C : 55 - 69
D : < 55
Lulus : >= 70
Tidak Lulus : < 70

## Alur Program
Mulai

Tampilkan menu

1. Input nilai
   - validasi nama
   - validasi nilai
   - simpan data

2. Statistik
   - hitung rata-rata
   - nilai tertinggi
   - nilai terendah
   - jumlah lulus
   - jumlah tidak lulus

3. Predikat
   - tampilkan nama
   - tampilkan nilai
   - tampilkan grade
   - tampilkan status

4. Keluar

Selesai
